How do I set up a streaming route in Next.js 14 App Router using the official @google/generative-ai SDK with Edge Runtime?

auto_awesome
Gemini 1.5 Flash • 10:42 AM

To achieve ultra-low latency streaming with the Google Gemini API in Next.js 14 App Router, configure your route handler with Edge Runtime and consume the streaming iterator via native Web Streams (ReadableStream).

check_circle Runtime Directive: Export runtime = 'edge' to bypass Node.js cold-boot penalties.
check_circle SDK Streaming: Utilize model.generateContentStream() yielding asynchronous chunk buffers.
check_circle Chunk Encoding: Pipe text segments into a TextEncoder() UTF-8 byte stream.
app/api/chat/route.ts 
import { GoogleGenerativeAI } from '@google/generative-ai';

// Enforce ultra-fast Edge runtime
export const runtime = 'edge';

const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY!);

export async function POST(req: Request) {
  const { prompt } = await req.json();
  const model = genAI.getGenerativeModel({ model: 'gemini-1.5-flash' });

  const result = await model.generateContentStream(prompt);
  const encoder = new TextEncoder();

  const stream = new ReadableStream({
    async start(controller) {
      for await (const chunk of result.stream) {
        controller.enqueue(encoder.encode(chunk.text()));
      }
      controller.close();
    },
  });

  return new Response(stream, {
    headers: { 'Content-Type': 'text/plain; charset=utf-8' },
  });
}

On your client React component, you can consume this using the standard response.body.getReader() stream loop or hooks from Vercel AI SDK.
